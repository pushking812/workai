# Этапы 2–4: схемы, комплекты, интерфейс, запросы Power Query

Состояние на 2026-11-12. Этапы 1 и 3 описаны в `stage1.md` и `stage3.md`.

## Разбор документов
- Типы документов: `core/doc_types.py` (ВОР, КЖ, СО, СВОР; `С` сохраняется как `СО`). Алиасы типов задаются в настройках («Типы документов…»).
- Штамп (`core/parsers/stamp_parser.py`): номер и дата изменения берутся из верхней заполненной графы «Изм.» над подписями (`latest_change_row`); пустые и «-» пропускаются.
- Шапки и данные (`core/parsers/header_profiles.py`):
  - продолжение таблицы без шапки: ширина не меньше шапки, лишние пустые колонки справа обрезаются;
  - номера в начале наименования переносятся в колонку номера, если не менее 75% непустых наименований начинаются с номера и номер вписывается в нумерацию соседних строк;
  - строка-перенос наименования (нет номера, заполнено только наименование, нумерация продолжается) склеивается с предыдущей;
  - нечисловой текст в колонке номера не переносится, а попадает в `number_issues`;
  - скобки в `№ п/п` не правятся, сомнительные значения (`18)`) помечаются.
- Справочник заголовков: `core/header_dictionary.py`, схема БД версии 8.
- Нумерация Word: `scripts/docx_fix_numbering.py` (подключается из `core/parsers/numbering_fix.py`).

## Комплекты (`core/kits.py`)
- Комплект = шифр + номер изменения + дата. Шифр и изменение определяет путь: папка шифра, `ИЗМ0/ИЗМ1`, `Ред. формат` игнорируется, `Книга 1/2` объединяются.
- Штамп, противоречащий пути, даёт пометку «ⓘ». «Сохранить» показывает диалог: ОК принимает комплект как есть (`kit_forced`), Отмена не сохраняет.
- Дата комплекта — дата изменения из штампа; дата документа — дата в имени файла, иначе дата изменения.
- Настройки: корень, комплекты, типы документов, фильтр слов (целое слово, до открытия файла), фильтр папок (только вложенные, по началу названия, без регистра и пробелов; по умолчанию «Изм», «Ред. формат»).
- Дерево «по комплекту»: шифр → Изм.N → комплект.

## Интерфейс (`ui/`, `api/`)
- Диалог «Заголовки без канонической роли»: строка на файл с путём; щелчок открывает файл в Word (`Controller.open_document`).
- Во время сохранения кнопка «Сформировать запросы» заблокирована.

## Запросы Power Query (`core/query_builder.py`)
- Кнопка «Сформировать запросы»: одна книга на тип документа, внутри все комплекты. Книга — копия шаблона в `data/queries/`, таблица списка файлов на CSV.
- Шаблоны: `PQ/ВОР/шаблон ВОР.xlsx`, `PQ/СО/шаблон СО.xlsx` (собирается `scripts/make_so_template.py` из `PQ/СО/запросы/*.pq`). Книги `.xlsx` в git не входят (`.gitignore`).
- `scripts/pq_sync.py`: `export`, `import [--dry-run]`, `list` для обмена запросами с книгой.
- `ВОР_База`: `СсылкаНаЧерСпе` убирается последним шагом.
- СО, `ФайлBinary`: пункты с одним `NПП` и совпадающими остальными полями (кроме `КолВо`, `Примечание`) сворачиваются: объём с единицей измерения добавляется в примечание, объёмы суммируются, примечания объединяются через `; `.

## Не проверено / открыто
- Запросы в Excel (`ВОР_База`, `ФайлBinary`, `ВОР_СвязьСО`, шаблон СО) на реальных данных; окно приложения.
- Шаблоны КЖ и СВОР, общая книга ВОР+СО по `КлючСО`, `generate_mapping_report`, `data_applier.apply_mapping`, сквозной тест, этапы 5–6.
- После изменений разбора старые CSV нужно удалить: «Сохранить» не перечитывает файлы с готовым CSV.
